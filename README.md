# A pirâmide de IA pra dominar o Instagram

Não é sobre usar todas. É sobre ter uma ferramenta certa em cada camada.

## 1. Cérebro

| Ferramenta | Pra quê | Link |
|---|---|---|
| ChatGPT | roteiros, ganchos, legendas e ideias de pauta em volume | https://chatgpt.com |
| Claude | textos longos, análise de concorrentes e revisão de copy | https://claude.ai |

**Dica:** antes de pedir qualquer coisa, cole quem é seu público, o que ele teme e o que ele deseja. Exemplo:

```
Meu público: [QUEM É, IDADE, PROFISSÃO].
O maior medo dele: [MEDO].
O que ele mais quer: [DESEJO].
Com base nisso, me dê 10 ganchos para um carrossel sobre [TEMA].
```
